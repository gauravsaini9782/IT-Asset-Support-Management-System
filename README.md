# IT Asset & Support Management System

## Project Overview

The IT Asset & Support Management System is a web-based information system designed to help organisations manage their IT assets and employee technical support requests.

The system allows IT administrators to register and manage company assets such as laptops, monitors, mobile phones, and other IT equipment. These assets can be assigned to employees and their current status can be tracked.

Employees can log in to the system, view the IT assets assigned to them, and create support tickets when they experience technical problems with their assigned equipment.

IT support staff can view support requests, assign tickets, update their priority and status, add comments, and mark issues as resolved.

## Main Users

1. Employee
2. IT Administrator / Support Staff

## Main Purpose

The purpose of the system is to provide a centralised platform for managing organisational IT assets and technical support requests instead of maintaining asset information and support issues separately.

## User Roles

### Employee
- Register and log in to the system
- View personal profile
- View assigned IT assets
- Create support tickets for assigned assets
- View own support tickets
- Add comments to own tickets
- Track ticket status

### IT Administrator / Support Staff
- Log in to the system
- View the administrative dashboard
- Manage employees
- Add, view, update, and archive IT assets
- Assign and unassign assets to employees
- View all support tickets
- Assign support tickets
- Set ticket priority
- Update ticket status
- Add comments to support tickets
